# 🎵 MPZ Studio

> Свободный плеер и конструктор для форматов **`.mpz`** (музыка) и **`.vpz`** (видео).

## Что это

**MPZ Studio** — десктопное приложение для воспроизведения и создания
собственных форматов `.mpz` (Music Parent Zip-pack) и `.vpz` (Video Parent Zip-pack).

Оба формата — открытые контейнеры на основе ZIP. Внутри одного файла хранится:

- 🎵 аудио или 🎬 видео,
- 🖼 обложка,
- 📝 текст песни / субтитры,
- 🏷 метаданные (название, исполнитель, год, жанр),
- 🔊 дополнительные дорожки (минус, акапелла, комментарий, дубляжи).

Всё в одном файле — удобно хранить, пересылать, слушать оффлайн.

## Возможности

| Функция | Описание |
|---|---|
| **Аудио в 3 качествах** | MQ (192 kbps), HQ (320 kbps), Hi-Fi (440 kbps) |
| **Видео 480p / 720p / 1080p** | С субтитрами и главами |
| **Bass Boost** | Усиление до +18 дБ |
| **Скорость** | 0.5×–2× с изменением тона |
| **Синхронизация текста** | LRC, TTML, VTT, SRT |
| **Обложки** | JPG, PNG, WebP |
| **Soundpack** | Несколько дорожек в одном файле |
| **Конструктор внутри** | Создание `.mpz` и `.vpz` без сторонних программ |

## Установка

### Windows (готовый `.exe`)

1. Скачай `MPZ-Player.exe` из раздела [**Releases**](../../releases/latest).
2. Двойной клик по любому `.mpz` или `.vpz` и выбери MPZ Player а затем "Всегда".
3. Теперь можно открыть `.mpz` или `.vpz` буквально вне программы.

git clone https://github.com/levkryzankov-spec/mpz-studio.git
